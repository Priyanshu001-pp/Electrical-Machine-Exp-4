Summary

Aim

The aim of this experiment is to study the speed control of a DC shunt motor by armature voltage control method and to plot the graph between armature voltage and motor speed.

Simulation Summary

Connections were made as per the circuit diagram. The DC motor was started using the starter. Armature voltage was varied gradually using the rheostat. For each voltage setting, the corresponding motor speed was noted. Readings were recorded in the observation table and a graph between armature voltage and speed was plotted.

Components

  • DC Power Supply
  • Starter
  • Field Rheostat
  • Armature Rheostat
  • DC Shunt Motor
  • DC Voltmeter
  • DC Ammeter
  • RPM Indicator

Key Parameters

  • Voltmeter Range: 0 to 410 V
  • Ammeter Range: 0 to 1 A
  • Speed Range: 0 to 2000 RPM
